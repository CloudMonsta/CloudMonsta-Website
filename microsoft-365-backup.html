What backup helps protect against

Not every data-loss event is dramatic. Many start with a simple mistake that is not noticed until much later.

Accidental deletion

A user deletes an email, file or folder and realises it is needed after the normal recovery window has passed.

User departures

A licence or account is removed before the business has retained the data it may need later.

Malicious or unauthorised changes

Files or mailbox contents are deleted, altered or encrypted by a compromised account or malicious user.

Retention gaps

Built-in retention settings do not always match the length of time the business expects to keep data.

Syncing mistakes

A local deletion or file change synchronises into Microsoft 365 before anyone realises what happened.

Operational recovery

The business needs a faster and more straightforward way to restore specific items, folders or user data.

How recovery works

When something is lost, the aim is to understand what happened, locate the right recovery point and restore the required data.

1

Identify the data

Confirm the user, mailbox, site, folder or file involved and when the data was last known to be correct.

2

Check available recovery points

Review the protected data and locate an appropriate backup version.

3

Restore the required content

Recover the item, folder or data set using the available restore options.

4

Validate the result

Confirm the restored content is accessible and meets the business requirement.

Frequently asked questions

Does Microsoft 365 already include backup?

Microsoft provides service resilience and built-in recovery features, but these are not the same as having an independent backup designed around your own retention and restore needs.

What data can be protected?

The service is designed to protect Exchange Online, OneDrive, SharePoint and Teams-connected data, subject to the capabilities of the selected backup platform.

How long is data retained?

Retention depends on the backup service and configuration selected. CloudMonsta will explain the available retention options before setup.

What happens when an employee leaves?

Protected data can remain available according to the backup retention policy, even after the Microsoft 365 user account or licence has been removed, subject to the service terms.

Can individual emails or files be restored?

Yes, where supported by the backup platform. Restore options can include individual items, folders, mailboxes, sites or broader data sets.

Is backup monitored?

Backup status monitoring can be included so failed or incomplete protection can be investigated rather than going unnoticed.

Can backup be added later?

Yes. Backup can be added to an existing Microsoft 365 environment, although protection only begins once the service has been configured.
