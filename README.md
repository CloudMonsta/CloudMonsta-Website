# CloudMonsta Website

The official CloudMonsta website.

CloudMonsta provides professional Microsoft 365 consultancy, business
websites, email migration, security, backup, and ongoing IT support for
small businesses across the UK.

**Website**\
https://www.cloudmonsta.com

------------------------------------------------------------------------

## Features

-   Responsive HTML5 website
-   Azure Static Web Apps hosting
-   GitHub Actions CI/CD deployment
-   Microsoft 365 service pages
-   Advice Centre with practical guides
-   Machine-Tech customer case study
-   Appointment Website showcase
-   Business Website showcase
-   Contact forms
-   SEO optimisation
-   Custom 404 page
-   Sitemap and robots.txt
-   Google Analytics integration

using GitHub Actions.
